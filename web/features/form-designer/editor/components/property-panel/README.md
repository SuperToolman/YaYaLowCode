# 属性面板公共层

字段属性和表单属性共用此目录，不依赖具体字段类型、接口或 schema。

- `PropertyLayout.tsx`：标题、分组、行与区块布局。
- `PropertyControls.tsx`：HeroUI 基础控件与统一样式。字号为 `text-xs`，有尺寸选项的控件使用最小的 `sm`；不固定控件高度。
- `../field-properties/`：字段规则、选项、默认值和数据加载。例如 `MemberProperties` 负责成员来源、范围和成员/角色请求；下拉展示使用公共控件。
- `../page-properties/`：表单属性和页面资源配置。

新增普通输入、数值、下拉、开关或分段选择时优先复用公共控件。选项、值转换与保存回调由业务组件提供。成员/表单/字段选择器、公式编辑器等专用业务控件继续使用各自模块，不在公共层引入。
