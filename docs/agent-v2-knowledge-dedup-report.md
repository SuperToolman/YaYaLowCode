# 知识检索跨库精确去重（2026-11-10）

## 行为与范围

检索先检查任务冻结范围与当前访问权限，再合并召回候选中正文一致的片段。身份使用 SHA-256：CRLF/CR 统一为 LF，再做 Unicode NFC；保留大小写、空格、数字、标点和数组/表格正文。存储字节的原有 SHA-256 完整性校验保持不变。不做模糊或语义去重。

关键词降级路径、混合 RRF、可选重排及跨 profile 合并均在最终条数截取前处理重复片段。每个召回列表对同一正文最多贡献一次 RRF 排名；同一资料同时命中关键词与向量仍可正常获得融合分数，重复上传不会额外累加。重排同一 profile 内只发送一份正文；跨 profile 合并取排名靠前者，重复副本不叠加分数。

每个结果保留兼容主来源字段，新增 `sources`，记录全部实际召回且仍有效的独立引用。模型只接收一份正文；页面可打开各来源。检索持久记录继续只保存引用标识和分数，恢复时重新检查每个来源并重新分组，主来源失效时可由有效副本接替。读取文档分页不合并，保持原始页序及游标。

不合并数据库文件、知识库、文档或版本，不改变员工包，不跨权限补查来源，不新增迁移，不触发索引重建。删除某个来源不删除其他知识库的副本。去重限于当前召回窗口；窗口外的相同文档不保证列出。不同切分边界、不同解析结果不会自动合并。
