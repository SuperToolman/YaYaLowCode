## 2. 关键源码核对

- `agent-v2/core/src/domain.rs`：当前命令为 Prompt、Confirm、Cancel，没有完整会话生命周期或 steer 等命令。
- `api/src/modules/agent_v2.rs`：会话列表/创建/详情、消息、命令、事件、确认等路由存在；未提供完整会话搜索、归档、恢复和彻底删除入口。附件发送恢复不是会话归档恢复。
- `agent-v2/cordis-host/src/host.mjs`：真实使用 Cordis，但固定导入 diagnostic；`plugin.activate` 要求重启固定插件集，没有形成通用已安装市场插件的动态运行链路。
- `agent-v2/worker/src/runtime.rs`：初始化 checkpoint 时按 `queue_seq <= 当前任务` 读取历史消息；前端分页不会限制模型上下文。长会话仍需上下文压缩、预算与工具调用/结果配对策略，否则有窗口超限、延迟与成本增长风险。
- `api/src/modules/agent_v2/tools.rs`、`design.rs`、`preview.rs` 与 `agent-v2/core/src/tools.rs`：平台工具、设计保存/补丁、权限和预览有真实实现，但注册存在不等于逐工具验收通过。
