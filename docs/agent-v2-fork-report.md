# AgentV2 会话分叉实施记录

日期：2026-11-06。对应现阶段计划 B05。状态：代码已实现，编译与静态检查；数据库和用户操作链路未验收。

## 交互与范围

- 已完成且持久保存的助手回复右侧增加“从此回复分叉”图标，使用 HeroUI 和 Gravity UI。
- 点击确认后创建独立会话并切换，原会话及其正在执行的后续任务保持原状。确认文案明确当前未发送草稿会清空。
- 边界固定为选中助手回复所在的已完成轮次，包含此前终态轮次。存在未结束的前序任务、非助手消息、未保存回复或跨会话消息时拒绝。
- 历史消息和可见说明作为只读历史快照；不重新执行模型、工具或原业务写入。首次新模型请求只在用户发送新消息时启动。
- 不复制旧确认、effect_key、工具 invocation、运行 checkpoint、权限快照、模型配置、Skill 环境变量、原始推理或脚本依赖环境。
- 新任务按当前员工、安装、许可证、用户 RBAC 和新任务快照重新准备，不继承原任务的执行授权。

## 数据合同

- 新增平台迁移 `m20261106_000113_session_forks`，不改历史迁移。
- session 保存不带外键的来源会话/消息标识 `fork_origin`；run 保存 `history_snapshot`。
- 历史轮次使用新 command/run/message ID，command 为不可执行的内部 `history_snapshot` 标记，run 直接保存原终态，不进入任务队列。
- 仅复制消息所引用附件，以及边界内轮次已经登记的正式产物；不复制未来轮次文件或未登记的本地 scratch 文件。
- 文件采用字节独立复制并生成新 ID，不共享源文件所有权或依赖源会话下载。消息中的 fileId 和对应工作区下载地址同步重写。
- 工作区仍限制 100 MiB / 200 文件；缺失引用或超限整体事务回滚，不创建部分会话。
- 不复制解析缓存，后续按需读取/解析。文件展示以新会话工作区为准。
- 历史快照不计作新模型请求或重复 token 消耗，不展示虚假的执行时长。
- 保留可见说明与历史终态；工具执行卡、确认操作和原始工具结果不复制为可执行记录。本批不是完整工具运行日志克隆。
- 源会话和分叉会话独立归档/删除，源删除不级联目标。删除目标仍保留最小分叉请求身份，旧请求不能重建已删除目标。

## API 与幂等

`POST /api/agent/v2/sessions/{session_id}/fork`：

```json
{"clientRequestId":"UUID","messageId":"UUID"}
```

返回目标会话。前端本次确认重试复用请求 ID；服务端按部署、用户及请求 ID 去重，冻结源会话和消息，不允许同键替换边界。源会话加锁，复制过程与归档/删除协调。

使用生成 SDK 和既有 Next BFF POST 代理，不新增手写 HTTP 请求。分叉来源标识不提供跨用户读取通道，所有访问继续走现有会话归属和员工使用权校验。

## 用户手动验收清单

1. 选择中间一条已完成回复分叉，确认后续轮次未复制，新会话无 queued/running 任务。
2. 查看旧消息及历史说明，确认标记为历史快照，无重复 token 消耗；正常发送新消息后模型能继续对话。
3. 对含图片、办公附件和正式产物的会话分叉，核对新文件 ID、内容和下载地址。
4. 在专用测试会话删除源会话，确认分叉消息及文件仍可访问；删除目标不得影响源会话。
5. 同请求重复提交、响应丢失后重试、替换 messageId、跨用户/员工和归档/删除竞争分别验证。
6. 确认没有复制历史写入、待确认卡、脚本环境或配置秘密；新执行需要独立安装的依赖按当前合同处理。
