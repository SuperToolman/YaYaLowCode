## 思考设置收敛（当前）

- 供应商弹窗保留思考模式开关、参数协议和默认强度。仅思考模式、允许关闭思考、支持档位的配置链路已移除，包括 DTO、预设、持久读写及执行判断。

- 增量迁移 `m20261105_000110_simplify_thinking` 清理三个废弃配置列，历史迁移保持不变。迁移尚未在当前数据库执行，需要启动新版 API 应用。
- 不增加工具调用、图片输入、自定义协议或输入输出上限配置。
- OpenAPI 和生成 SDK 同步更新；未运行回归或浏览器测试。
