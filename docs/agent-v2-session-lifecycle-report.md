# AgentV2 会话管理与归档设置页实施记录

日期：2026-11-06。状态：已实现并进行编译/静态检查，未运行数据库、浏览器或自动化回归验收。

## 交付范围

- 主工作台会话列表支持按员工过滤、服务端标题/消息搜索、游标分页、置顶和标题修改。
- 会话归档入口保留在工作台的当前会话操作栏，已归档列表移至 `/settings/agent-archives`。
- 设置页导航位于“AI员工 → 归档会话”，使用既有 `agent.window` 权限；只管理当前用户自己的会话，管理员不读取他人会话。
- 归档页支持标题、消息内容、标题和内容三种搜索范围；单条/批量恢复，单条/批量彻底删除，删除前统一确认。
- 每批最多 100 个会话，逐项返回结果，部分失败不会被整体成功提示掩盖。全选针对当前已加载的可操作记录，不代表所有搜索结果。
- 可以查看归档消息并分页读取旧消息。员工已过期或卸载时，归档目录仍按已有员工使用权显示；恢复和读取消息仍需现有员工可用性校验。

## 数据与接口

新增平台增量迁移：

- `m20261106_000111_session_directory`：置顶、归档时间、自定义标题标记和独立元数据版本，以及列表索引。
- `m20261106_000112_session_deletion`：删除请求时间和持久删除任务。

两份新 SQL 同步用于独立测试库初始化；本批不修改历史迁移、不实际执行测试库或客户库迁移。

接口：

- `GET /api/agent/v2/sessions`：`employee_id/search/search_in/archived/cursor/limit`，返回 `items/next_cursor`。
- `PATCH /api/agent/v2/sessions/{id}`：标题、置顶、归档和恢复；要求 `expectedVersion`，冲突时刷新重试。
- `POST /api/agent/v2/archived-sessions/actions`：`sessionIds` 和 `restore/delete`，逐项反馈。

OpenAPI、生成 SDK、Next BFF 同步，不手写第二套 HTTP 合同。搜索为服务端大小写不敏感子串搜索，支持中文匹配，不是 RAG 或语义检索。消息内容范围为用户/助手文本及已提交步骤的可见说明，不搜索私有推理、模型配置、原始工具参数或附件二进制；不提供全文相关度排序，容量表现待实测。

## 归档与删除规则

- 有未结束任务时拒绝归档；归档保留消息与文件，禁止新增任务和工作区写入。
- 恢复只改变归档状态，不重新执行历史命令；已进入删除流程的会话不可恢复。
- 删除只接受已归档且没有未结束任务或待核对执行的会话。`outcome_unknown` 不自动当作已停止。
- 删除请求先持久锁定会话并阻止后续访问；后台每 5 秒处理一个任务，使用 PostgreSQL 事务级 advisory lock 避免多个 API 并行清理同一批资源。
- 先请求本地 manager 清理对应会话环境及 job 目录，再在数据库事务中清理消息、步骤、工具调用、确认、效果和审计记录、事件/outbox、正式文件及解析缓存。
- 删除不撤销已经执行的平台业务变更。
- 发送请求清除正文、附件暂存和提交结果，仅保留原幂等键/指纹及删除标记，防止旧请求重放生成新会话；标记不参与普通 30 天元数据清理。
- manager 校验部署/用户/员工/会话范围和实际删除路径，拒绝活跃、未知结果、范围冲突或不可读取状态；留下无内容的 scope hash 删除标记，拒绝晚到执行请求。
- 数据库删除完成后保留最小删除任务状态及主体标识，不保留会话正文、标题、文件、执行日志或可恢复副本。这是逻辑/文件删除，不承诺存储介质安全擦除，也不清理用户另行保存的文件。
- manager 不可用、目录被占用或数据库清理失败时，列表显示清理失败并允许重新提交删除；不能将已受理显示为已完成。删除已开始时不提供撤销。

## 启动与手动验收

正常退出当前开发脚本后，在项目根目录执行：

```powershell
.\scripts\start-dev.ps1
```

需要新版 API 应用迁移，Worker、execution manager 与 Web 配套更新。不能只刷新前端；旧 manager 没有删除端点，会使清理失败。当前未替用户重启整套服务或操作数据库。

建议用明确命名的测试会话进行手测，不删除正式业务会话：

1. 改名、置顶，刷新验证持久性；多个标签页修改同一标题应得到冲突而非静默覆盖。
2. 创建足够会话后加载更多，切换员工与搜索，确认旧请求不覆盖新条件。
3. 执行期间归档应拒绝，结束后归档应移出主工作台。
4. 在设置页分别以标题、用户正文及助手可见说明搜索。
5. 查看归档消息；恢复后应返回主工作台且不重复执行工具。
6. 多选恢复，确认逐项结果；筛选切换不应对当前不可见会话执行批量操作。
7. 使用包含附件、产物和脚本依赖的测试会话，确认删除后不能查看或下载，目录与日志确实清理。
8. 暂停 manager 后请求删除，确认显示失败；恢复 manager 后重试，不能恢复已删任务或重复业务效果。
9. 双标签页重复删除/恢复、删除与发送竞争、跨用户或员工越权需要独立实际验证。
