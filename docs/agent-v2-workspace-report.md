# AgentV2 附件与会话工作区实施记录

日期：2026-10-29。状态：首批附件/逻辑工作区已实现，文本真实链路通过；P6 和完整 V2 尚未完成。

## 交付行为

- 消息框支持多文件选择、拖放、粘贴、附件单独发送和移除待发送引用。移除引用不会删除工作区对象。
- 选择、拖放、粘贴的附件先暂存在浏览器内存，不创建会话或上传；点击发送后先建立独立发送请求并上传临时附件，全部就绪后事务内创建/复用会话及保存消息、任务；详见 2026-11-02 更新。发送期间锁定会话/员工切换。历史图片可查看，文件可下载。
- 复用 V2 自有 `WorkspaceFiles` 组件，使用 MySurface/HeroUI，无旧 Agent feature 导入。
- 新增 `workspace_list_files`、`workspace_read_file`、`workspace_write_file`。模型通过显式工具保存产物；普通回答不自动变成文件。
- 文件及 `workspace.file.created` 事件同事务持久化；刷新后重新选择员工/会话恢复消息与文件，SSE 重连重新读取目录。

## 存储与隔离

工作区为 PostgreSQL 逻辑工作区，文件内容为 bytea，不是 Shell 可访问的物理目录。迁移 `m20261029_000103_agent_v2_workspace` 使用平台增量迁移机制。

文件不可变，以 UUID 标识并关联会话；会话固定绑定部署、用户和员工。列表/上传/下载重新检查会话所有者、用户、员工使用权、许可证及安装。管理员不能读取其他用户会话。消息事务校验附件属于当前会话，拒绝重复引用与伪图片引用。所有 API 均不接受用户磁盘路径。

Worker 文件及工具入口使用内部凭据和执行证明，重新检查任务策略与员工版本；模型附件只可来自当前 run 可见消息历史。输出保存锁定会话及 run，检查执行 epoch、运行/取消状态。`(run_id, invocation_id)` 唯一约束和内容核对保证重放不重复生成；相同文件幂等 ID、不同内容返回冲突。配额检查在会话锁内串行执行。

二进制 BFF 原样转发字节并保留鉴权。下载响应设置 private/no-store、nosniff、CSP sandbox 和安全 UTF-8 文件名。签名识别的 PNG/JPEG/WebP 可显示，其余附件下载；签名识别不是完整图片解码或病毒扫描。

## 格式及限额

| 项目 | 当前范围 |
| --- | --- |
| 上传 | 单文件 1 字节至 8 MiB，每消息最多 8 文件、合计 16 MiB |
| 会话 | 100 MiB、200 文件 |
| 读取 | UTF-8 文本/CSV/JSON 等，单文件最多 256 KiB |
| 图片 | PNG/JPEG/WebP 经 Rig 原生图片 part 发送，需模型支持视觉 |
| PDF/Office/其它二进制 | Office/文字 PDF 已接入受限 helper 和有界基础样本；其它格式保存下载，不宣称模型已读取 |
| 生成 | UTF-8 文本最多 256 KiB；不执行代码或导出 Office/PDF |
| 请求预算 | 每次模型请求累计历史附件最多 24 MiB，超限明确失败 |

后续仍需：分片/断点续传、正式文件完整回收、文件搜索、OCR、供应商视觉能力提示、物理沙盒和插件二进制产物发布。临时附件清理与基础文档提取已增量接入，范围见发送链路报告。响应丢失后相同上传 ID 可去重；用户重新选择文件产生新 ID。会话彻底删除/保留期清理仍待实现，外键级联不代表产品删除链路完成。文件进入数据库备份，后续评估对象存储和容量策略。

## 接口与启动

- GET/POST `/api/agent/v2/sessions/{session_id}/files`：目录/上传。
- GET `/api/agent/v2/sessions/{session_id}/files/{file_id}`：私有下载。
- 内部 run 文件读取及 `/workspace/invoke`：仅 Worker，身份从任务解析。
- OpenAPI 与生成 SDK 已同步，前端使用生成合同。

```powershell
.\scripts\start-dev.ps1 -SkipLegacyAgent -SkipDshBuild
.\scripts\check-agent-v2.ps1 -UseLocalDevelopmentDatabase -Offline
.\scripts\check-agent-v2.ps1 -UseLocalDevelopmentDatabase -Offline -DesignOnly
```

依赖 Rig 0.40.0、Cordis 4.0.0-rc.12。启动验收未启动旧 DSH。

## 会话交互修复补记（2026-11-02）

- 点击“新建会话”只进入空白草稿并解除原会话订阅，不创建数据库空会话。首次发送使用原有创建/提交链路，首条文本通过现有服务端逻辑生成标题（最多 48 字符）。附件也必须等到发送时才上传到所属会话。
- HeroUI 会话列表直接声明 `ListBox.Item`，统一由 `onSelectionChange` 驱动当前会话，避免列表选中与展示状态脱节。重复选择当前会话不清空消息；切换时清理原会话消息、确认、附件及工作区状态。
- 历史请求及 SSE 回调检查当前会话/取消信号，旧会话晚到的消息、连接状态或权限失效事件不能覆盖新会话。
- 页面回归 9 项通过，含重复新建不落库、首次发送、往返切换、重复点击、旧事件及延迟历史响应；相关前端范围回归合计 4 文件 17 项通过，修改文件 ESLint 通过。证据：`agent-v2/target/session-ui-tests.log`、`agent-v2/target/session-ui-regression.log`。本次未执行已登录浏览器与真实模型端到端验收。

### 附件延迟提交修正

- 不论是否已有会话，待发送附件只保留本地 File 和稳定客户端附件 ID，不提前进入工作区。移除附件、新建草稿、切换会话或员工会释放对应草稿引用；刷新不保留未发送附件。
- 点击发送后按“创建会话（如需要）→ 上传全部附件 → 提交消息”执行；文件仍由现有服务端会话接口执行用户、员工及会话隔离检查。任一附件上传失败时不提交消息。
- 上传失败后保留草稿、已有会话及成功上传结果；重试复用客户端附件 ID，只上传未成功项。消息提交失败后继续使用原命令幂等键和已上传文件，避免重复上传。发送锁同步阻止重复发送及中途切换。
- 覆盖选择/拖放/粘贴后零创建零上传、附件单独发送、移除/导航后不落库、部分上传失败恢复及消息失败重试。V2 前端范围回归 6 文件 28 项通过，修改文件 ESLint 通过；最终证据：`agent-v2/target/draft-attachments-regression.log`。未将 mock 接口页面测试表述为实际浏览器端到端验收。


## 临时附件与原子发送更新（2026-11-02）

新发送框已改为冻结请求 → 两文件并发二进制暂存 → 原子转正/消息/任务提交；旧直接上传接口保留。选择文件不创建会话也不上传；已有会话的待发送附件也不提前进入工作区。仅已点击发送请求支持刷新恢复，缺少本地字节时重新选择校验。Office 样本在 Worker 中准备，持久状态可查询并在工作区展示。
